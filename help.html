📋 Ringkasan Aplikasi

Aplikasi input & rekap speed mesin cutting beserta suhu thermocontrol dan jejer per mesin. Data tersimpan di Google Sheets melalui Google Apps Script.

🚀 Cara Input Data

  1. Pilih Tanggal & Shift di panel Kontrol Produksi.
  2. Klik salah satu tombol mesin di panel Daftar Mesin.
  3. Isi No SPK — bisa diketik manual atau scan barcode (tombol 📷).
  4. Tunggu preview SPK muncul (hijau = valid).
  5. Isi Speed (pcs/menit).
  6. Pilih Jejer dari dropdown (1 s/d max).
  7. Isi Suhu (jika mesin punya thermocontrol).
  8. Tekan OK untuk menambah baris (masuk pending).
  9. Ulangi untuk mesin lain, lalu tekan Simpan ke Sheet Inputan untuk mengirim semua pending sekaligus.

✅ Validasi SPK

SPK dianggap valid kalau:

  • Ditemukan di database SPK (file ARD di Google Drive), DAN
  • Punya Panjang Pot (bukan kosong, bukan 0).

Kalau tidak punya Panjang Pot → muncul pesan "Bukan SPK Potong! Panjang Pot kosong." dan tombol OK dinonaktifkan.

🔍 Format Preview SPK

Notasi preview:

Jenis [Cetak <Cetakan>] Tebal x Lebar[/Lipat] x PanjangPot        BD BD
  • Contoh tanpa cetakan: PP Keunguan 0,08 x 20/12 x 25 BD 17
  • Contoh dengan cetakan: PP Keunguan Cetak Ayam Bawang Ungu 0,08 x 20/12 x 25 BD 17
  • Tebal 0,1 tampil 0,10; tebal 0,2 tampil 0,20.
  • Lipat tampil (/lipat) hanya kalau ada isi & bukan 0.
  • Cetak tampil hanya kalau kolom "Cetakan Tambak Rejo" di DB SPK ada isi.

🔢 Jejer

Jejer = berapa banyak plastik rol yang disusun berjajar dalam sekali potong. Nilainya angka (1 sampai nilai maksimum yang dikonfigurasi).

  • Pilih jejer dari dropdown di overlay input (setelah Speed, sebelum Suhu).
  • Wajib diisi — tombol OK tidak akan aktif kalau jejer belum dipilih.
  • Nilai maksimum jejer dikonfigurasi admin di sheet Mesin cell J2.
  • Jejer juga tampil di card list mesin, detail cell rekap, dan rekap per mesin.

📊 Cara Rekap

  1. Pindah ke tab Rekap Speed.
  2. Pilih Tanggal Awal dan Tanggal Akhir (maks 7 hari).
  3. Centang Shift yang ingin ditampilkan.
  4. Klik Tampilkan Rekap.
  5. Double click / tahan pada cell speed untuk melihat detail (No SPK, Spesifikasi, Speed, Jejer, Suhu).
  6. Double click / tahan pada nama mesin untuk melihat rekap lengkap mesin tersebut.

⏰ Default Tanggal & Shift Otomatis

  • Tanggal default: hari ini, kecuali jam < 06:00 → kemarin (cutoff awal shift pagi).
  • Shift default:
    • 06:00 – 13:59 → PAGI
    • 14:00 – 21:59 → SORE
    • 22:00 – 05:59 → MALAM
  • Nilai ini hanya di-set saat halaman dibuka / refresh. Kalau diubah manual, tidak ketimpa.

🌡️ Satuan

  • Speed: pcs/menit
  • Suhu: °C
  • Jejer: angka (1 s/d max)

💾 Edit & Hapus

  • Edit pending: baris yang belum disimpan bisa diubah lewat tombol ✏️ Edit.
  • Edit server: baris tersimpan bisa diubah, langsung dikirim ke server.
  • Hapus: pending atau server, dengan konfirmasi.

📝 Catatan

  • Suhu boleh kosong (mesin mati / tidak punya thermocontrol tertentu).
  • Jejer wajib diisi — tidak boleh kosong.
  • Anti-dobel: baris identik dalam 200 baris terakhir akan dilewati.
  • Pastikan jam device benar (auto time) supaya tanggal & shift otomatis akurat.
  • Kalau update file ARD (DB SPK), jalankan clearCache() di editor GAS supaya web langsung mengenali SPK baru.
